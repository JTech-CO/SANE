## 구성

영문·한국어 **11쌍의 텍스트 문서 22개**와 `CHECKSUMS.sha256`로 구성된다. 하나의 `sane/` 루트 안에 **총 23개 파일**이 있다. 체크섬은 모든 텍스트 문서를 포함하며 체크섬 파일 자신은 의도적으로 제외한다.

`SKILL.md`는 메타데이터·제목을 포함해 **53줄**, **공백 구분 단어 855개**이다. `LITE.md`는 제목을 포함해 **18줄**, **공백 구분 단어 273개**이다. 파일의 측정값이지 모델 토큰 수가 아니다. 한국어판의 크기는 다르며 같은 토큰 사용량을 주장하지 않는다.

## 실제 수행한 패키지 검사

| 검사 | 결과 | 근거 범위 |
| --- | --- | --- |
| UTF-8·LF 줄바꿈·마지막 줄바꿈·문자 대체 오류 없음 | PASS | 모든 텍스트 문서 |
| 영문·한국어 대응 파일 존재 | PASS | 문서 11쌍 전체 |
| 규칙·사례·예시·출처 ID 일치 | PASS | 언어 쌍의 식별자 집합 일치. 번역 품질의 자동 입증은 아님 |
| 핵심 메타데이터 | PASS | YAML 파싱, `name: sane`과 부모 폴더 일치, 필드 길이·문자열 메타데이터 확인 |
| 핵심 문서 크기 | PASS | 두 진입 문서 모두 500줄 미만 |
| 규칙 누락 | PASS | 두 언어의 핵심·LITE·규칙·검수·행동 사례 문서에 S01~S10 포함 |
| 행동 사례 누락 | PASS | 두 언어에 T01~T16 제공, NOT_RUN 명시 |
| 상대경로 Markdown 링크 | PASS | 파싱한 모든 로컬 파일 링크가 패키지 내부의 실제 파일로 연결 |
| Markdown 파싱과 코드 블록 | PASS | 표를 포함해 markdown-it-py로 파싱, 코드 블록 시작·종료 일치 |
| 문서의 POSIX 복사 절차 | PASS | 임시 디렉터리에서 두 어댑터 경로 실행, 기존 목적지 보호 확인 |
| 불필요한 바이너리·런타임 코드 | PASS | 폰트 바이너리·실행 파일·설치 훅·런타임 스크립트 없음 |
| 체크섬과 ZIP 왕복 확인 | PASS | SHA-256 파일 확인, ZIP 무결성 검사, 안전한 경로, 압축본을 읽은 바이트 비교 |

핵심 메타데이터는 공개 형식 제약에 맞춰 로컬에서 확인했다. 공식 검증기 인증이나 실제 호스트 설치 시험은 아니다. Markdown 파싱은 브라우저의 시각적 배치 검사가 아니다.

## 실행하거나 입증하지 않은 것

PowerShell 예제는 실행하지 않았다. Codex·Claude Code·ChatGPT·Grok·DeepSeek·로컬 모델 호스트를 실행해 패키지를 로딩하지 않았다. 여러 모델의 벤치마크, 샘플 앱 렌더링, 네이티브 앱 접근성 검사, 디자인 품질 개선의 실증은 수행하지 않았다. [행동 검증 사례](ACCEPTANCE-KR.md)는 **NOT_RUN** 상태이다.

출처·어댑터 설명을 위해 공개 참고문서를 확인했다. 문서가 존재한다고 모든 계정·플랫폼·버전·설치 환경의 실시간 사용 가능성이 입증되는 것은 아니다.

패키지 유효성·지시문 이식성은 모델 준수·시각 품질과 다르다. 이 보고서를 모든 AI에서 보기 좋고 접근 가능하며 동일한 결과를 보장한다는 주장으로 바꾸지 않는다.

# SANE: Signal Above Needless Embellishment

Apply this minimum design contract to the requested UI. Preserve scope, working behavior, real data, explicit brand choices, and existing tokens; follow host instruction priority. Do not redesign unrelated work.

1. **S01:** Start with the user's question or action, not a component inventory.
2. **S02:** Make the first reading or working priority clear; avoid equal-weight card grids unless the items are genuine peers.
3. **S03:** Reuse a small type/spacing/radius scale. Keep essential text readable; never shrink it to hide overflow.
4. **S04:** Give space to useful content, not an empty hero chart. Preserve honest axes, outliers, and necessary whitespace.
5. **S05:** Make tables scannable, values recoverable, and narrow-screen access usable. No decorative sort/filter controls.
6. **S06:** Put quantities, units, periods, and category meanings beside values or axes; no hover-only essentials.
7. **S07:** Expose the important result with a valid comparison when available. Never invent data; distinguish zero, missing, and loading.
8. **S08:** Remove repeated information that serves no new task. Keep necessary context and accessible alternatives.
9. **S09:** Use a coherent semantic palette, not automatic neon, glow, glass, or random accents. Honor deliberate themes.
10. **S10:** Select typography for tone, hierarchy, and language coverage. Familiar/system fonts are allowed when chosen intentionally.

Keep keyboard access, focus, contrast, non-color status cues, readable enlargement, and working in-scope controls. Dark mode, cards, color, and whitespace are not banned. Do not replace clutter with a generic blank template.

Deliver the requested result. Fix known in-scope blockers; report unresolved limitations. Check the affected rendered UI when tools permit, and label unavailable checks as not verified. No extra process documents or compulsory redesign phases.

# 호스트별 적용법

[English](USAGE.md) | [처음으로](../README-KR.md)

**범용성은 지시문을 재사용할 수 있다는 뜻이지, 모든 제품의 설치 방식이 같다는 뜻이 아니다.** 모델, 호스트 앱, 스킬 로더는 서로 다른 계층이다. SANE을 전달해도 파일 접근, 렌더링 도구, 영구 저장 권한이 새로 생기지 않는다.

## 가장 작은 적용 경로 선택

| 호스트 또는 사용 화면 | 적용 경로 | 중요한 한계 |
| --- | --- | --- |
| ChatGPT 웹·데스크톱·모바일, Astra 포함 | `LITE-KR.md`와 작업 요청을 붙여 넣거나 진입 파일을 첨부하고 읽기를 명시 | 이 ZIP이 자동으로 설치된 ChatGPT 플러그인이 되는 것은 아님 |
| 로컬 스킬을 지원하는 Codex CLI·IDE | `sane/`을 `.agents/skills/sane/`에 복사하고 `/skills`에서 선택하거나 `$sane`으로 호출 | 클라우드·앱 환경에는 해당 환경에서 접근 가능한 복사본과 로딩 기능이 필요 |
| Claude 웹·데스크톱·모바일 | `LITE-KR.md`를 붙여 넣고, 해당 호스트에 커스텀 스킬 가져오기가 있으면 이용 | 로컬 Claude Code 설치가 모든 Claude 세션에 자동 적용되지는 않음 |
| Claude Code | `sane/`을 `.claude/skills/sane/`에 복사하고 `/sane`으로 호출 | 기존 스킬은 검토 없이 덮어쓰지 않음 |
| Grok·DeepSeek 채팅 앱 | 실제 요청과 함께 `LITE-KR.md`를 붙여 넣음 | 공통 네이티브 `SKILL.md` 로더를 가정하지 않음 |
| 로컬 AI 또는 다른 모델을 사용하는 채팅 실행기 | `LITE-KR.md`를 붙여 넣거나 허용된 작업별 지시 입력란에 추가 | 실행기·컨텍스트 한도·모델에 따라 동작하며 모델 파일 자체가 스킬을 설치하지는 않음 |
| 파일 읽기를 지원하는 일반 CLI·IDE 에이전트 | 프로젝트의 알려진 경로에 두고 `SKILL.md`를 읽도록 요청 | 파일을 읽지 못하는 환경에서는 경로만 언급해도 적용되지 않음 |
| API·자체 앱 | 앱이 선택 파일을 UTF-8로 읽어 작업과 함께 지시문 본문으로 전달 | 공급자의 메시지 형식을 따르고 기존 앱 정책을 유지 |

네이티브 경로와 호출법은 [OpenAI·Claude 공식 문서](../references/SOURCES-KR.md)에서 확인했다. 다른 행은 텍스트 전달 전략이며 검증된 네이티브 연동을 뜻하지 않는다. 정확한 메뉴, 계정별 사용 자격, 향후 버전까지 보장하지 않는다.

## 채팅과 첨부 파일

선택한 파일 본문을 붙인 뒤 작업 요청을 추가한다. 두 언어판이나 LITE와 SKILL을 동시에 붙이지 않는다. 읽을 수 있는 파일을 첨부했을 때는 다음처럼 요청할 수 있다.

```text
첨부한 SKILL-KR.md를 읽고 다음 UI 작업에 적용한다.
관련 자료는 구체적인 문제가 있을 때만 읽는다. 읽을 수 없다면
진입 파일에 있는 독립적인 규칙을 적용한다. 범위와 브랜드를 보존한다.
[실제 작업, 원본 자료, 제약, 기대하는 출력]
```

대괄호 줄은 작업 내용을 넣는 자리이지 필수 입력 양식이 아니다. 모든 무관한 대화에 인터페이스 규칙을 상시 적용하지 않는다. 비공개 코드나 데이터는 권한 없이 업로드하지 않는다.

## 안전한 프로젝트 설치

압축을 푼 **원본 `sane/` 폴더가 있는 프로젝트 디렉터리**에서 실행한다. 목적지는 하나를 선택한다. 명령은 파일만 복사하며 클라우드 플러그인 등록이나 전역 에이전트 정책 변경을 수행하지 않는다.

### Bash·POSIX 셸: Codex

```sh
if [ -e .agents/skills/sane ]; then
  printf '%s\n' 'Destination exists. Review it before replacing.' >&2
  exit 1
fi
mkdir -p .agents/skills
cp -R sane .agents/skills/sane
```

Claude Code에서는 명령에 나오는 `.agents/skills`를 모두 `.claude/skills`로 바꾼다. 마지막 폴더명은 `sane`을 유지한다.

### PowerShell: 목적지 선택

```powershell
# Codex. For Claude Code, use '.claude/skills/sane' instead.
$target = '.agents/skills/sane'
if (Test-Path -LiteralPath $target) {
    throw 'Destination exists. Review it before replacing.'
}
New-Item -ItemType Directory -Path (Split-Path $target -Parent) -Force | Out-Null
Copy-Item -LiteralPath './sane' -Destination $target -Recurse
```

프로젝트 단위가 아닌 개인 설치의 공식 위치는 Codex의 `~/.agents/skills/sane/`, Claude Code의 `~/.claude/skills/sane/`이다. 여러 복사본을 의도적으로 관리하는 경우가 아니라면 범위를 하나만 선택한다. 실제 호스트에서 인식되는지 확인하고 필요하면 새 세션을 시작한다.

### 설치 후 호출

Codex:

```text
$sane 첨부한 대시보드의 라벨과 시각적 위계를 고친다.
기존 테마, 경로, 데이터를 유지한다. 기능은 추가하지 않는다.
```

Claude Code:

```text
/sane 첨부한 대시보드의 라벨과 시각적 위계를 고친다.
기존 테마, 경로, 데이터를 유지한다. 기능은 추가하지 않는다.
```

선택기에서 이름을 인식하는 것은 로딩 확인이지 디자인 품질의 근거가 아니다. 결과는 별도로 확인한다.

## Astra: 얇은 계약과 명확한 완료점

LITE와 구체적인 결과물 요구로 시작한다. 이미 결정된 사항을 유지한다. 작은 변경 전에 역할극 패널, 전체 저장소 순회, 반복 자기 채점, 의무 기획 단계, 모든 참고자료 읽기를 요구하지 않는다. 더 정밀한 지시가 필요하면 LITE를 SKILL로 바꾸거나 해당 규칙 절만 추가한다. 같은 규칙을 중첩하지 않는다.

추가 요청 예시:

```text
제공된 SANE 계약을 이번 UI 변경에 적용한다. 기존 브랜드와 기능을
보존한다. 요청 구현과 알고 있는 범위 내 결함 수정을 완료하고,
실행할 수 없었던 시각적 검사를 밝힌다. 추가 절차 문서는 필요 없다.
```

이는 2026년 9월 11일 OpenAI 가이드의 좁은 적용 범위와 필요 시 로딩 방향을 따르며, Astra가 스킬을 사용할 수 없다고 주장하지 않는다. [출처](../references/SOURCES-KR.md)

## 기존 프로젝트 지시문

`AGENTS.md`, `CLAUDE.md`, 실행기의 시스템 프롬프트를 대체하지 않는다. 프로젝트 소유자가 포인터를 원한다면 **실제 설치 경로**를 사용해 기존 지침에 범위가 제한된 문장을 합친다.

```text
요청된 UI 작업에서는 <actual-path>/SKILL.md를 사용하고 해당 문제에
필요한 참고자료만 읽는다. 백엔드 전용 수정에는 적용하지 않는다.
```

`<actual-path>`는 실제 경로로 바꿔야 한다. 이 패키지는 자동 로딩되는 루트 에이전트 파일, 훅, 권한, 공급자 전용 도구 선언을 의도적으로 제공하지 않는다.

## 언어와 유지관리

네이티브 진입점의 기본 언어는 영어이다. 한국어는 `-KR` 문서를 사용하거나 별도 설치 복사본에서 `SKILL.md`를 `SKILL-KR.md`로 교체한다. `name: sane`과 상대경로를 유지하며 영문·한국어 중복 설치를 피한다. 메타데이터 이름을 함께 바꾸지 않고 폴더명만 버전명이 붙은 형태로 바꾸지 않는다.

업데이트할 때는 기존 설치 버전을 비교한 뒤 교체한다. 인식되지 않으면 호스트 공식 문서를 확인한다. 모든 실패를 모델의 지시 불이행으로 판단하지 않는다. 로더나 파일 도구가 없다면 LITE 본문을 붙여 넣는 방식으로 돌아간다.

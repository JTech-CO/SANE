# SANE
## Signal Above Needless Embellishment

**AI가 만드는 인터페이스를 위한 최소 디자인 계약.** 핵심 정보는 남기고, 불필요한 혼란은 줄이며, 제품의 개성은 유지한다.

[English](README.md) | 버전 **1.0.0** | 참고자료 확인: **2026-09-15**

SANE은 대시보드에서 반복되는 열 가지 실패를 인터페이스 제작·수정·검토에 적용할 수 있는 구체적인 제약으로 바꾼다. 영문을 기본으로 하며 모든 문서의 한국어판을 제공한다. UI 키트, 고정 스타일, 자율 에이전트, 모델 파인튜닝이 아니다.

## 파일 하나로 시작하기

**일반 채팅:** [LITE-KR.md](LITE-KR.md)의 내용을 실제 요청 앞에 그대로 붙여 넣는다. ChatGPT, Claude, Grok, DeepSeek, 로컬 모델 등 텍스트 지시를 받을 수 있는 호스트에서 가장 적은 의존성으로 사용하는 방법이다. 파일 이름만 적는다고 모델이 내용을 읽을 수 있는 것은 아니다.

**파일을 읽는 에이전트:** [SKILL-KR.md](SKILL-KR.md)를 제공하고 사용을 명시한다. 필요할 때만 관련 참고자료의 해당 절을 읽도록 한다.

**네이티브 스킬 로더:** 압축을 푼 `sane/` 폴더를 호스트가 스킬을 탐색하는 위치에 설치한다. 진입점은 `sane/SKILL.md`이다. [호스트별 적용법과 안전한 복사 명령](adapters/USAGE-KR.md)을 참고한다. 이 패키지는 독립형 스킬이며, 배포된 ChatGPT 플러그인이나 모든 제품에 통하는 원클릭 설치기가 아니다.

**LITE와 SKILL 중 하나**, **영문과 한국어 중 하나**만 사용한다. ZIP 전체를 의무적인 컨텍스트로 넣지 않는다.

### 계약 뒤에 붙이는 요청 예시

```text
지연 배송을 찾아야 하는 고객지원 담당자를 위해 이 주문 대시보드를 수정한다.
기존 다크 테마, 데이터셋, 필터는 보존한다. 조치가 필요한 예외와
읽기 쉬운 비교를 우선한다. 기능은 추가하지 않는다.
변경 파일과 중요한 검증 한계를 제공한다.
```

영문 적용에는 [LITE.md](LITE.md)를 사용한다. 한국어를 네이티브 진입점으로 쓰려면 **설치용 복사본**에서 `SKILL-KR.md`를 `SKILL.md`에 덮어쓰고 `sane` 폴더명과 참고자료를 유지한다. 같은 이름으로 경쟁하는 스킬 두 개를 설치하지 않는다. 이 의도적인 변경 이후 해당 복사본은 원본 릴리스 체크섬과 일치하지 않는다.

| S05 | 잘리고 찾기 어려운 데이터 덤프 | 훑기 쉬운 표와 접근 가능한 상세 정보 |

| S08 | 자리를 채우기 위한 정보 반복 | 사실마다 대표 위치를 두되 필요한 맥락 유지 |

## 무조건 금지하지 않는 것

다크모드, 흔한 서체, 시스템 폰트, 카드, 여백, 여러 차트 색상, 고밀도 전문가 도구, 명시적으로 요청한 레트로·네온 브랜드는 그 자체로 잘못이 아니다. 문제는 검토하지 않은 선택, 읽기 어려움, 오해를 만드는 데이터, 목적 부재이다. 모든 제품을 똑같은 베이지색 미니멀 페이지로 바꾸지 않는다.

사이드바, KPI 줄, 대표 그래프, 구매 유도 버튼, 폰트 다운로드, CSS 프레임워크, 신규 의존성, 애니메이션을 요구하지 않는다. 패키지는 분석 추적, 네트워크 요청, 설치 후 실행 훅, 실행용 런타임 코드를 추가하지 않는다. 실제 AI 호스트의 권한과 동작은 해당 호스트가 유지한다.

## Astra와 작은 컨텍스트에서의 사용

Astra를 비롯해 얇은 계약이 적합한 환경에서는 **LITE와 실제 작업 요청**으로 시작한다. 원하는 결과, 보존할 사항, 완료 기준을 명시한다. 구체적인 문제가 생겼을 때만 관련 참고자료를 추가한다. 이는 패키지 설계 방식이지 Astra가 스킬을 무시한다거나 짧은 프롬프트가 더 나은 결과를 보장한다는 주장이 아니다. 근거와 확인한 공식 가이드는 [SOURCES](references/SOURCES-KR.md)에 연결되어 있다.

## 검증 범위와 한계

이 릴리스는 파일, 링크, 언어 쌍, 규칙 누락, ZIP 무결성을 확인한다. 행동 검증용 사례는 제공하지만 여러 모델에서 완료한 벤치마크로 제시하지 않는다. 네이티브 스킬 인식, 시각적 품질, 모델의 실제 준수는 대상 호스트에서 평가해야 한다. SANE 검수를 통과했다고 WCAG 인증을 받은 것은 아니다.

실제 검증 범위는 [RELEASE-CHECK](tests/RELEASE-CHECK-KR.md)에 있다. `sha256sum`을 제공하는 환경에서 압축 해제한 `sane/` 안에서 다음 명령으로 체크섬을 확인할 수 있다.

```sh
sha256sum -c CHECKSUMS.sha256
```

패키지의 신규 작성 본문에는 [MIT 라이선스](LICENSE.txt)를 적용한다. 연결된 글, 규격, 상표, 제3자 자료에는 각각의 조건이 유지된다. 제3자의 스크린샷, 폰트 바이너리, 아티클 복제본은 포함하지 않는다.

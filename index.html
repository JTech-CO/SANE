Structure first. Readability next. Intent throughout. Open any principle for the practical version.구조를 먼저 잡고, 읽기 쉽게 정리하고, 선택에 의도를 담는다. 각 원칙을 펼치면 구체적인 적용 방향을 확인할 수 있다.

  1. S01Lead with the task.사용자의 일부터 시작한다.Not a wall of widgets.위젯을 늘어놓지 않는다.

    Start with the user’s question or action. Put the answer or working area first, supporting context next, and detail where it is needed.

    사용자의 질문이나 행동에서 출발한다. 답이나 작업 영역을 먼저 두고, 이를 뒷받침하는 맥락과 세부 정보를 순서대로 배치한다.

  2. S02Give the eye a starting point.먼저 볼 곳을 정한다.Not equal weight everywhere.모든 요소를 같은 무게로 두지 않는다.

    Make primary, supporting, and background content visibly different. A grid of identical cards is appropriate only when the items really are peers.

    핵심, 보조, 배경 정보의 무게를 구분한다. 실제로 동급인 항목이 아니라면 모든 내용을 같은 카드로 감싸지 않는다.

  3. S03Use a scale, not guesswork.크기를 규칙 있게 사용한다.Not tiny type and random spacing.작은 글자와 제각각인 여백을 피한다.

    Reuse a compact set of type sizes, spacing, and corner radii. Essential text must stay readable; never shrink it just to hide overflow.

    소수의 글자 크기, 간격, 모서리 척도를 일관되게 재사용한다. 핵심 내용이 넘친다고 글자를 줄여 감추지 않는다.

  4. S04Make every chart earn its space.그래프의 공간에 이유를 둔다.Not an oversized empty hero.비어 있는 대형 그래프를 앞세우지 않는다.

    Size a chart for the question it answers. Keep useful whitespace, honest axes, and outliers. Simplify the presentation without changing the data’s meaning.

    그래프가 답하는 질문에 맞게 크기를 정한다. 필요한 여백, 정직한 축, 이상치를 지키고 데이터의 의미를 바꾸지 않은 채 표현을 정리한다.

  5. S05Make tables worth reading.표를 읽을 수 있게 만든다.Not a clipped data dump.잘린 데이터 덩어리를 내놓지 않는다.

    Choose useful columns, sensible ordering, and readable headers. Keep full values recoverable on small screens. Sort and filter controls must actually work.

    유용한 열, 의미 있는 순서, 명확한 헤더를 사용한다. 작은 화면에서도 전체 값을 확인할 수 있어야 하며 정렬과 필터는 실제로 동작해야 한다.

  6. S06Put meaning beside the number.숫자 옆에 의미를 둔다.Not labels that need decoding.추측해야 하는 라벨을 피한다.

    Keep units, periods, categories, and relevant denominators close to their values. Do not make essential meaning depend on hover, color, or a distant subtitle.

    단위, 기간, 분류, 필요한 분모를 값 가까이에 표시한다. 핵심 의미를 마우스 오버, 색상, 멀리 있는 부제목에 의존시키지 않는다.

  7. S07Bring the real signal forward.실제 핵심을 드러낸다.Not buried or invented insights.핵심을 숨기거나 비교를 지어내지 않는다.

    Show the important result and a valid baseline when one exists. Never invent a trend to make a design more impressive. Distinguish zero, missing data, and loading.

    중요한 결과와 유효한 비교 기준을 함께 보여준다. 화면을 그럴듯하게 만들기 위해 추세를 지어내지 않는다. 0, 결측, 로딩을 구분한다.

  8. S08Repeat only with a reason.필요한 정보만 반복한다.Not the same fact in three places.같은 값을 세 군데에 되풀이하지 않는다.

    Give each fact one primary home. Repeat it only for useful local context, a different task, or an accessible alternative. Remove filler, not explanation.

    각 정보의 주된 자리를 정한다. 필요한 맥락, 다른 작업, 접근 가능한 대체 표현을 위한 반복은 허용한다. 설명이 아니라 군더더기를 없앤다.

  9. S09Choose a palette with a purpose.색상에 역할을 부여한다.Not automatic neon and glow.형광색과 발광 효과를 기본값으로 쓰지 않는다.

    Use stable roles for emphasis, status, and categories. A deliberate dark or neon brand can stay. Accidental decoration is the problem, not color itself.

    강조, 상태, 분류에 일관된 색상 역할을 부여한다. 의도된 다크 테마나 네온 브랜드는 유지한다. 문제는 색 자체가 아니라 무심코 더한 장식이다.

  10. S10Choose type that can do the job.읽는 사람에게 맞는 서체를 쓴다.Not untouched defaults or novelty.기본값 방치도, 낯설기만 한 폰트도 피한다.

    Choose for tone, hierarchy, numerals, and language coverage. A familiar or system font is valid when it fits. Check Korean and Latin text, wrapping, and fallback behavior.

    분위기, 위계, 숫자, 언어 지원에 맞게 서체를 고른다. 목적에 맞는 익숙한 서체나 시스템 폰트는 허용한다. 한국어와 영문, 줄바꿈, 대체 서체를 확인한다.

Change the presentation. Preserve the data and working behavior.표현은 고치되, 데이터와 정상 동작은 지킨다.

# SANE: Signal Above Needless Embellishment

Apply this minimum design contract to the requested UI. Preserve scope, working behavior, real data, explicit brand choices, and existing tokens; follow host instruction priority. Do not redesign unrelated work.

1. **S01:** Start with the user's question or action, not a component inventory.
2. **S02:** Make the first reading or working priority clear; avoid equal-weight card grids unless the items are genuine peers.
3. **S03:** Reuse a small type/spacing/radius scale. Keep essential text readable; never shrink it to hide overflow.
4. **S04:** Give space to useful content, not an empty hero chart. Preserve honest axes, outliers, and necessary whitespace.
5. **S05:** Make tables scannable, values recoverable, and narrow-screen access usable. No decorative sort/filter controls.
6. **S06:** Put quantities, units, periods, and category meanings beside values or axes; no hover-only essentials.
7. **S07:** Expose the important result with a valid comparison when available. Never invent data; distinguish zero, missing, and loading.
8. **S08:** Remove repeated information that serves no new task. Keep necessary context and accessible alternatives.
9. **S09:** Use a coherent semantic palette, not automatic neon, glow, glass, or random accents. Honor deliberate themes.
10. **S10:** Select typography for tone, hierarchy, and language coverage. Familiar/system fonts are allowed when chosen intentionally.

Keep keyboard access, focus, contrast, non-color status cues, readable enlargement, and working in-scope controls. Dark mode, cards, color, and whitespace are not banned. Do not replace clutter with a generic blank template.

Deliver the requested result. Fix known in-scope blockers; report unresolved limitations. Check the affected rendered UI when tools permit, and label unavailable checks as not verified. No extra process documents or compulsory redesign phases.

Keep the skill with the project.프로젝트에 스킬을 함께 둔다.

Copy the complete SANE package into the project’s skill directory, keeping the references and the SKILL.md entry point together. Review an existing installation before replacing it.참고자료와 SKILL.md 진입점을 포함한 SANE 패키지 전체를 프로젝트의 스킬 폴더에 복사한다. 기존 설치가 있다면 덮어쓰기 전에 확인한다.
